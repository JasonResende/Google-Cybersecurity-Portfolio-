# Python Security Automation
This folder contains scripts used to automate repetitive security tasks, reducing human error and increasing response speed.

### Featured Project: Automating Allow List Updates
* **The Problem:** Manually updating access lists for hundreds of IP addresses is time-consuming and prone to errors.
* **The Solution:** A Python script that parses a text file, removes unauthorized IPs using a 'remove list,' and updates the file automatically.
* **Key Skills:** File I/O, String Manipulation, Iterative Loops.

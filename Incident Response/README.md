# Incident Response Documentation
In cybersecurity, documentation is just as critical as the technical fix. This folder contains formal reports on security incidents.

### What's Inside:
* **Technical Incident Reports:** Detailed breakdowns of simulated security breaches (e.g., Botium Toys).
* **NIST Framework Alignment:** Reports organized by the Identify, Protect, Detect, Respond, and Recover functions.
* **Key Skills:** Technical Writing, Risk Assessment, Incident Lifecycle Management.
